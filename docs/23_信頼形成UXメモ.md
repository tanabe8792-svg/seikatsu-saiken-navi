## 開発者表現

**「一学生」を前面に出す。** 「一個人開発」だけを前面に出さない。

| 表現 | 被災者への印象 |
|------|---------------|
| 一個人開発（前面） | 技術者・サービス提供者っぽい |
| **一学生（前面）** | 熊本の地域課題に向き合う **人間味** |
| 一学生のみ | 責任感が弱く見える可能性 → **セット表現** が必要 |

被災者にとって重要なのは「企業が作ったか否か」より **「誰が何の思いで作っているか」**。

### 売りにしない / 売りにする

| ❌ | ✅ |
|----|-----|
| 「個人開発者です！」 | **地域にいる一学生が、必要だと思ったものを作り、声を聞きながら育てている** |

### 原則

- 熊本で学ぶ **一学生** が開発している（**主語・前面**）
- **個人開発・個人運営** であることは隠さない（**補足・誠実さ**）
- 未熟さの言い訳に **しない** — 声を聞き改善する **強み** として表現

### 個人運営を伝えるとき — 必ずセットで出す

1. **公式情報をもとに整理する**
2. **推測で案内しない**
3. **利用者の声で改善する**

### About 想定コピー（2段落・たたき）

**段落1 — 想い・一学生（前面）**

```
熊本で学ぶ一学生が、熊本地震で被災された方々の生活再建を
少しでも支えられるように開発しています。
```

**段落2 — 個人運営・改善姿勢（誠実さ）**

```
個人で開発・運営しているため、至らない点もあるかもしれません。
実際に使われる方の声を聞きながら、より安心して利用できる
サービスへ改善していきます。
```

## 3. 情報の扱い方（情報の責任表現）

**絶対に入れる。** 突き放す表現は禁止。「一緒に確認する」スタンス。

### 悪い例

```
情報の正確性は保証できません。最終判断は自己責任でお願いします。
```

### 良い方向

```
支援制度や手続きの内容は変更される場合があります。
このサービスでは公式情報を確認しながら整理のお手伝いをします。
大切な判断の際は、最新の情報をご確認ください。
```

### NG（一覧）

- 最終判断は自己責任でしてください
- 情報が変わるので自分で確認してください
- 情報の正確性は保証できません（単独で使わない）

### 推奨コピー（たたき・伴走版）

```
生活再建に必要な情報を整理してお届けします。
ただし、支援制度や申請期限などは変更される場合があります。
大切な判断の前には最新の公式情報も確認しながら、
安心して進められるようサポートします。
```

### ③ との分担

| 層 | 役割 |
|----|------|
| 信頼形成レイヤー「情報の扱い方」 | ③ の表側 — サービス全体の約束 |
| 「なぜこの案内が出ているか」details | ③ の表側 — 個別案内の根拠 |
| KB / sourceUrl（既存） | ③ の裏側 |

## 4. ご意見・改善受付

単なる問い合わせフォームではなく、

**「生活再建ナビへのご意見・改善のお願い」**

> このサービスをより役立つものにするための声を聞かせてください

### フォーム項目（候補）

| 項目 | 目的 |
|------|------|
| 使っていて分かりにくかったところ | UX friction |
| 追加してほしい情報 | コンテンツ不足 |
| 困っていること | 被災者の実態 |
| 改善してほしいところ | 機能・案内 |
| 応援メッセージ | モチベーション（任意） |

### 受け取りたい声の種別

| 種別 | 例 |
|------|-----|
| 被災経験者 | 実体験に基づくフィードバック |
| 支援者 | 家族・自治体・ボランティア視点 |

### 目的

フィードバックを **改善に接続** — 「一学生が声を聞きながら育てている」の具体化。
