# 登録メールのエラーを止める手順（ゆうさん向け）

画面に出る「登録用メールを送れませんでした」は、**アプリのプログラムではなく、メールを送る設定（Supabase）側**で止まります。  
下の手順で止められます。所要時間の目安は15〜20分です。

---

## いま起きていること（短く）

1. 利用者が「登録用メールを送信」を押す  
2. Supabase がメールを送ろうとする  
3. **送れない** → エラーになる  

なので、**Supabase に「ちゃんとメールを送れる設定（SMTP）」を入れる**のが対処です。

改善の声で使っている **Resend** があれば、同じものを使えます。

---

## 手順A — Resend で送れるようにする（おすすめ）

### 1. Resend を開く

1. https://resend.com にログイン  
2. まだ API キーがなければ **API Keys → Create API Key** で作成し、キーをメモ  

### 2. 送り元メール（From）を用意する

1. Resend → **Domains** でドメインを追加して認証する  
   - 例: `mail.あなたのドメイン`  
2. 認証が終わったら、送り元の例:  
   `熊本 生活再建ナビ <noreply@あなたのドメイン>`  

（ドメインがまだ無い場合は、Resend の試験用 `onboarding@resend.dev` では **自分の Resend 登録メール宛にしか送れない**ことがあります。本番ではドメイン認証が必要です。）

### 3. Supabase に SMTP を入れる

1. https://supabase.com/dashboard で、このナビのプロジェクトを開く  
2. 左メニュー **Project Settings**（歯車）  
3. **Authentication**  
4. 下の方 **SMTP Settings** を開く  
5. **Enable Custom SMTP** を ON  
6. 次を入れる  

| 項目 | 入れる内容 |
|------|------------|
| Sender email | `noreply@あなたのドメイン`（Resend で認証したアドレス） |
| Sender name | `熊本 生活再建ナビ` |
| Host | `smtp.resend.com` |
| Port | `465`（または `587`） |
| Username | `resend` |
| Password | Resend の **API Key**（`re_...` で始まるもの） |

7. **Save**

### 4. メールログインが ON か確認

1. Supabase → **Authentication** → **Providers** → **Email**  
2. **Enable Email provider** が ON  
3. Save

### 5. 戻り先 URL を確認

1. Supabase → **Authentication** → **URL Configuration**  
2. **Site URL**  
   `https://seikatsu-saiken-navi.vercel.app`  
3. **Redirect URLs** に次があること  
   - `https://seikatsu-saiken-navi.vercel.app/auth/callback`  
   - （開発するとき）`http://localhost:3000/auth/callback`

### 6. アプリで確認

1. https://seikatsu-saiken-navi.vercel.app/mypage を開く  
2. メールを入れて「登録用メールを送信」  
3. 届いたメールのリンクを開く → 登録完了  

届かないときは **迷惑メール** も見てください。

---

## 手順B — すぐ使いたいとき（メールの代わり）

メール設定が終わるまで、利用者には **LINE で登録・ログイン** を案内してください。  
進捗（やること）はこの端末に残ります。

---

## よくある勘違い

| 勘違い | 実際 |
|--------|------|
| すでに登録済みだからエラー？ | いいえ。新規も既存も同じ「メール送信」です。送れない＝送信設定の問題が多いです |
| アプリのプログラムを直せば直る？ | 画面の案内は直せますが、**送れない本体は SMTP 設定**です |
| Vercel の Redeploy だけで直る？ | SMTP を入れない限り直りません |

---

## チェックリスト（全部できたらエラーは止まる想定）

- [ ] Resend の API Key がある  
- [ ] Resend で送り元ドメインを認証した  
- [ ] Supabase の Custom SMTP を ON にした  
- [ ] Host が `smtp.resend.com`、Username が `resend`、Password が API Key  
- [ ] Email provider が ON  
- [ ] Site URL / Redirect URL が本番 URL になっている  
- [ ] マイページからテスト送信して、メールが届いた  

---

わからない画面名があったら、その画面のスクショを送ってください。こちらで「次に押すボタン」まで書きます。
