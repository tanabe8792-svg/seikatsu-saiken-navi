## 1. Cursor（こちら）ができること / できないこと

### できること（実施済み・または指示で実施可能）

- アプリの機能実装・文言調整・ビルド確認
- `vercel.json` などデプロイ設定の用意
- 公開手順書の作成
- （依頼があれば）Git の初回コミット文案・プッシュ準備

### できないこと（ゆうさんが必要）

| # | 作業 | なぜこちらではできないか |
|---|------|--------------------------|
| A | GitHub アカウント作成・ログイン | 本人のアカウントが必要 |
| B | GitHub にリポジトリを作ってコードを上げる | 認証・承認が必要（初回コミットも未作成） |
| C | Vercel アカウント作成・ログイン | 本人のアカウントが必要 |
| D | Vercel でプロジェクトを紐づけて Deploy | ブラウザでの接続承認が必要 |
| E | 独自ドメインの取得・DNS設定 | 契約・支払いが本人のみ |
| F | 確認メール送信（Resend 等）の本契約・APIキー | 外部サービスの契約と秘密鍵 |
| G | LINE 公式アカウント / Messaging API | LINE 側の事業者登録 |
| H | App Store / Google Play 提出 | ストア開発者契約（今は不要。Webで十分） |

**動画用ベータ公開に必須なのは A〜D だけです。**  
E〜H は「後からでよい」です。ドメインなしでも `*.vercel.app` の URL で公開できます。

## 3. ゆうさんが触る場所（クリック手順）

### ステップ1 — GitHub に上げる

1. ブラウザで https://github.com/signup （持っていれば https://github.com/login ）
2. 右上 **New repository**
   - Repository name 例: `seikatsu-saiken-navi`
   - Public でOK（ベータ公開用）
   - **Create repository**（README は作らなくてOK）
3. Cursor のチャットでゆうさんが言う:
   > 「初回コミットして GitHub にプッシュして」
4. こちらが `git commit` → `git remote add` → `git push` を実行  
   （途中で GitHub ログインを求められたら、ゆうさんがブラウザで承認）

### ステップ2 — Vercel で公開する

1. ブラウザで https://vercel.com/signup  
   - **Continue with GitHub** が一番簡単
2. **Add New… → Project**
3. さきほどの GitHub リポジトリを選ぶ
4. 設定を確認:
   - **Root Directory**: `app`（重要。リポジトリ直下ではなく `app`）
   - Framework: Next.js（自動検出されるはず）
   - Environment Variables: **今は空でOK**（キーなしで動く）
5. **Deploy** を押す
6. 終わると `https://○○○.vercel.app` の URL が出る → **これが動画用の公開URL**

### ステップ3 — 動画用に確認

スマホの Safari / Chrome でその URL を開き:

1. ブックマーク（お気に入り）に追加できるか
2. `/start` から状況入力 → やることまで進めるか
3. （任意）マイページ登録の画面が見られるか（通知はまだ届かない）

## 4. 「メール確認」「ドメイン」はいつ必要か

| やりたいこと | ドメイン | いま必要？ |
|--------------|----------|------------|
| 動画用に Web を公開 | 不要（vercel.app で可） | **今は不要** |
| 「このメールで合ってますか？」確認メール | あると届きやすい（なくても試験可） | 後でOK |
| 本番っぽい独自URL（例: saiken.example.jp） | 必要 | 後でOK |
| LINE で本当に通知 | 不要だが LINE 公式側の登録が必要 | 後でOK |

確認メールを後から入れるときの流れ（参考）:

1. https://resend.com （または類似）でアカウント
2. 送信ドメインを追加（または試験用アドレスのみ）
3. API キーを Vercel の Environment Variables に入れる
4. こちらが「確認メール送信」のコードを追加

---

## 5. 公開後にゆうさんがやること（運用）

- 公式リンク切れ・制度変更のチェック（県ナビ・市町村）
- フィードバック受付（改善の声・応援メッセージ）
  - Vercel に `TRUST_FEEDBACK_EMAIL`（ゆうさんの受信メール）を設定
  - 到達を確実にするには `RESEND_API_KEY` と `RESEND_FROM_EMAIL`（Resend で認証した From）も設定し Redeploy
  - 未設定だとフォームは「送信の準備がまだです」と表示されます
- 問題が出たら Cursor に「この URL でこう壊れた」と伝える
