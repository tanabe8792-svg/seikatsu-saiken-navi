## 1. 改善前の導線レビュー（実操作ベース）

| カテゴリ | 箇所 | 問題 |
|----------|------|------|

| **迷う** | やること一覧 | 7件が一度に並び、優先順位が視覚的に弱い |

```
ホーム → 状況を選ぶ（3タップ） → 最初のやること詳細 → 完了 → 次へ（自動）
```

### 改善後タップ数（熊本シナリオ）

|---|------|------|

## 3. 実施した体験改善（機能追加なし）

### ホーム

- マーケティング文・FAQリンクを削除
- 未設定時: 119/110/171 の緊急連絡 ＋ 単一の大CTA「状況を選んで、やることを見る」
- 設定済み: コンパクト緊急バー ＋「いま最初にやること」カード ＋「手順を見る」直行

### 状況入力（/start）

- 4ステップ → **3タップ**に短縮
- 市町村キーボード入力を**削除**
- 状況タグ追加: 子ども / 停電 / 水が出ない / 高齢者
- 完了後は**一覧を経由せず最初のやること詳細へ直行**

### やることリスト（/actions）

- 初回は「今すぐ」「1週間以内」のみ表示（「すべて表示」で展開）
- 次にやることへの大きなCTAを上部に固定
- 空状態は「状況を選ぶ」のみ（AIへの誘導を弱める）

### やること詳細

- セクションを簡素化（必要情報だけ）
- 固定フッター: **「完了した」→ 自動で次の手順へ**
- 「次へ」ボタンも常時表示

### ナビゲーション

- ボトムナビを **3タブ** に: ホーム | やること | その他
- AIチャットを主導線から外し、「その他」経由に

### その他（/mypage）

- プロフィール編集フォームを撤去
- 進捗表示 ＋ メニュー（状況を選び直す / AI相談 / 文字サイズ / FAQ / リセット）

### AI相談（/chat）

- ウェルカム文に「通信不安なら状況を選ぶ」を明記
- エラー時に「状況を選ぶ」へのフォールバックボタン

### 手順生成ロジック

- 停電・断水タグ → ライフライン確認を**「今すぐ」**優先度に
- 子どもあり → 避難・安否連絡の説明を家族向けに調整
- タイトルを平易な日本語に（例: 「まず自分と家族の安全を確認する」）

## 4. 残る改善余地（Phase 2候補・今回は見送り）

| 項目 | 理由 |
|------|------|
| オフライン時の完全ローカル手順 | 体験改善だが実装規模が大きい |
| 熊本市固有の避難所リンク | コンテンツ整備が必要 |
| 音声読み上げ | アクセシビリティ強化として別途 |
| 完了後の「今日はここまで」休憩導線 | 心理的配慮。小さなコピー追加で可能 |

## 6. まとめ

**Before:** 情報はあるが、被災直後のユーザーには「選ばせすぎ・入力多すぎ・一覧で止まる」  
**After:** 「3タップで最初の1歩 → 完了するたび次へ」という**行動OS**としての体験に寄せた

機能は増やさず、導線・優先度・文言・CTA・ナビ構造のみを変更しています。
