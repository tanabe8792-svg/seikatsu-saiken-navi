## Friction 記録

### F-001 — `/start` ラベル（P1 → **修正済**）

- **場所:** `/start` intro
- **状態:** 初回表示
- **迷った:** 「AIケースワーカー」が機能名か相手か
- **固かった:** AI が先に来て被災者向けサービスより技術印象
- **安心した:** 「状況の整理をはじめる」CTA、 reassurance ブロック
- **重要度:** P1
- **4つの問い:** ①○ ②○ ③○ ④○（AI が主役に見える → 生活再建が主役へ）
- **対応:** ラベルを「生活再建の伴走」に変更（`onboarding-copy.ts` / `onboarding-intro.tsx`）

### F-002 — 初回ホーム導線分散（P1 → **修正済**）

- **場所:** ホーム（caseFile あり）
- **状態:** J-00 完了直後
- **迷った:** 「ケースワーカーに相談」outline ボタン vs ヒーロー
- **固かった:** カード下部の同等 CTA
- **安心した:** 「次に一緒に確認すること」ヒーロー
- **重要度:** P1
- **4つの問い:** ①○ ②○ ③○ ④○
- **対応:** 相談を `<details>`「困ったとき・相談する」に格下げ + ヒーロー優先の一文（`home-dashboard.tsx`）

### F-003 — ホーム上部ラベル（P1 → **修正済**）

- **場所:** ホームカード上部
- **状態:** 初回〜再訪
- **迷った:** h1「生活再建ナビ」と「AIケースワーカー」の二重ラベル
- **固かった:** AI ラベル
- **安心した:** phaseDisplay.subtitle（発災直後/生活再建フェーズ）
- **重要度:** P1
- **対応:** 上部を `{phaseDisplay.title}` + subtitle に変更（AI ラベル削除）

### F-004 — ヒーロー内「なぜ」（P2 → **部分修正**）

- **場所:** ヒーローカード
- **状態:** J-00 直後
- **迷った:** details を開かないと理由が弱い場合がある
- **対応:** friendlyReason を headline と異なる場合 hero に表示
- **重要度:** P2
- **未対応理由:** 実機で重複表示にならないか要確認

### F-005 — 初回ホーム情報量（P2 → **未修正**）

- **場所:** 初回ホーム全体
- **状態:** welcome + 再建状況 + 現在 + hero + 折りたたみ群
- **迷った:** スクロール量
- **重要度:** P2
- **未修正理由:** 実機で疲れ感を確認後に判断

### F-006 — AI表現（観察継続 → **未修正**）

- **場所:** `/chat`、mypage「AI相談」
- **重要度:** P3 / A 以降
- **未修正理由:** B では主導線のみ。A で信頼形成とセット検討

### F-007 — J-00 ステップ3 ライフライン（P1 → **修正済**）

- **場所:** `/start` J-00 ステップ3（住宅被害 + ライフライン）
- **何が気になった:** 半壊を選んでもライフライン未タップだと「次へ」が無反応。理由の表示なし
- **被災者目線で何が不安か:** 「壊れているのかアプリが壊れているのか」わからず、入力が止まる
- **分類:** P1（次の行動が止まる）
- **Case1 再現:** 半壊選択 → 断水をタップし忘れ → 次へ disabled
- **対応:** ライフライン未選択時に amber ヒント表示（`start/page.tsx`）

### F-008 — J-00 ステップ1 サブタイトル（P2 → **未修正**）

- **場所:** `/start` J-00 ステップ1「どんな災害ですか？」
- **何が気になった:** サブタイトル「MVPでは地震を中心に案内します」が開発者向けトーン
- **被災者目線で何が不安か:** 未完成プロダクト・自分向けでない印象（操作は止まらない）
- **分類:** P2
- **未修正理由:** P1 基準外。実機で不安感が強ければ文言のみ変更を検討
