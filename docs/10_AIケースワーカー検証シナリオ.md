# AIケースワーカー検証シナリオ

被災者シナリオ6件で、Knowledge Base 接続済み AI ケースワーカーの判断が**地域・被害・属性によって異なるか**を検証する。

- **対象:** `app/src/lib/knowledge/` のトリガー・制度マッチング・Runtime Context
- **UI変更:** なし（本ドキュメントと validation コードのみ）
- **実行方法:** `cd app && npm run validate:scenarios`

---

## 検証の観点

| 出力 | 意味 |
|------|------|
| `matchedTriggers` | 発火したケースワーカートリガー ID |
| `matchedPrograms` | 条件・自治体スコープに合致した支援制度 ID |
| `priorityJourney` | 最優先トリガーが属するジャーニー（J-00〜J-06） |
| `priorityActions` | 優先度順の actionType / トリガー ID（上位3件） |

## Case 1: 宇城市・半壊・断水・子ども・持ち家

### 入力（CaseProfile）

| 項目 | 値 |
|------|-----|
| municipalityCode | `43442`（宇城市） |
| damageLevel | 半壊 |
| hasWaterOutage | true |
| hasChildren | true |
| housingTenure | 持ち家 |
| photoRecordStatus | none |

### 期待する判断

1. **水確保を最優先** — `TRIGGER-WATER-PRIORITY`、給水関連アラート
2. **写真撮影注意** — `TRIGGER-PHOTO-RECORD`（片付け前）
3. **罹災証明案内** — 宇城市窓口混雑アラート、罹災証明制度
4. **子ども関連確認** — `ALERT-WATER-CHILDREN` 系トリガー

### 期待トリガー（最低限）

- `TRIGGER-WATER-PRIORITY`
- `TRIGGER-PHOTO-RECORD`
- `TRIGGER-ALERT-ALERT-WATER-CHILDREN`
- `TRIGGER-ALERT-ALERT-UKI-CERT-CROWD`

### 期待 priorityJourney

`J-02`（ライフライン確保）

`J-01` または `J-05`（安全確保 / 住まい）
