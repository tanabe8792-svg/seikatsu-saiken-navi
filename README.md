# 生活再建ナビ

災害発生後の生活再建を支援するサービスです。被災者や支援者が必要な情報や手続きを見つけやすくし、生活再建のプロセスをナビゲートすることを目的としています。

## プロジェクト概要

| 項目 | 内容 |
|------|------|
| プロジェクト名 | 生活再建ナビ |
| 目的 | 災害時の生活再建支援 |
| ステータス | MVP 開発中 |

### 背景

大規模災害が発生した際、被災者は住居・生活基盤の再建、各種手続き、支援制度の利用など、多岐にわたる対応を短期間で行う必要があります。情報が分散していると、必要な支援や手続きを見落としやすく、生活再建が遅れる要因となります。

本プロジェクトは、被災者が状況に応じた情報や次に取るべきアクションを把握しやすくするサービスを提供することを目指します。

### 想定ユーザー

- **被災者** — 生活再建に必要な情報・手続き・支援制度を探している方
- **支援者** — 家族・地域・ボランティアなど、被災者を支援する方
- **自治体・支援機関** — 情報提供や支援施策の運用に関わる関係者（将来の検討事項）
