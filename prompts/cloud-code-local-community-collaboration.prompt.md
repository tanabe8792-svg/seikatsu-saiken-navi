# Cloud Code 用プロンプト：地域連携・大学教員への協力依頼文案

以下を Cloud Code（または同等の AI）に **そのまま貼り付けて** 実行してください。
出力は **コードではなく**、大学教員（地域連携ができる方）へ送る **短い協力依頼のたたき台** です。

---

## 貼り付け用プロンプト（ここから）

あなたは、被災者支援の Web サービス「熊本 生活再建ナビ」の協力依頼文案を書くアシスタントです。

### 背景（プロジェクト概要）

- **名称**: 熊本 生活再建ナビ
- **URL**: https://seikatsu-saiken-navi.vercel.app/
- **目的**: 令和8年熊本地震の被災者が、「この先何から手をつければいいか」を一人で抱え込まないよう、**やること・手順・公式リンク**を一緒に整理する無料の Web アプリ
- **位置づけ**: 行政の公式サービスではない。市町村と連携しておらず、画面を見せても窓口手続きは自動で進まない。公式情報を入口に、被災者自身が進められるよう伴走する
- **主な機能（概要のみ）**:
  - 状況に応じた「やること」一覧（罹災証明、保険連絡、給水、事業再建など）
  - 手順 → 準備 → 申請の順で読めるガイド、進捗の記録（端末内保存）
  - 熊本県内の自治体別申請案内（マイナポータル等へのリンク）
  - 被害写真の記録（端末内）、30分ごとの休憩リマインド
- **開発**: 個人（熊本学園大学大学院 会計専門職研究科・田辺 優）がボランティア経験等を背景に開発・更新。ベータ段階
- **いま欲しいこと**: **地域（町村・NPO・大学の地域連携）とつながる教員の方**に、**短時間で読める協力依頼**を送り、フィードバックや協力の可能性を相談したい

### 依頼者の立場（重要）

- 文案の発信者は **プロジェクト側（田辺 優）** です
- **相手の教員が書いた提案ではない** こと。教員への「お願い・相談」として書く
- 押し付けがましくなく、敬意を保つ。被災者の尊厳と、教員の時間を尊重する

### 出力してほしいもの

**1通分**の協力依頼文案（日本語）。次を満たすこと。

1. **長さ**: A4 1/2 ページ以内相当（箇条書き中心、800〜1200字目安）。提案を詰め込みすぎない
2. **構成**:
   - 冒頭：なぜ連絡するか（1〜2文）
   - サービス概要（3〜5行）
   - **協力をお願いしたいこと**（最大 **3点まで**。例：被災者・支援者視点のフィードバック、地域での周知方法の助言、学生・地域実践との接点の有無 など。全部お願いしない）
   - 教員側の負担を抑える書き方（オンライン30分、メール返信のみ、など選択肢を示す）
   - 締め：返信のしやすさ
3. **含めないこと**:
   - 詳細な技術仕様、コード、API
   - 行政・大学の公式承認があるかのような誤解を招く表現
   - 「必ず協力してください」などの強い要求
4. **トーン**: やさしい日本語。被災者向けアプリの理念に合う、誠実で控えめ

### 出力形式

- 件名案（1行）
- 本文（そのまま送れる形）
- 末尾に **「教員の方への確認事項」** を3つ以内（相手が返信しやすい質問）

以上に従い、文案のみ出力してください。解説や前置きは不要です。
